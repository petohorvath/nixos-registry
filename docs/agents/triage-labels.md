# Triage labels

Canonical triage roles map directly to GitHub label names.

| Role              | Tracker label     | Meaning                                              |
| ----------------- | ----------------- | ---------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer evaluation required                       |
| `needs-info`      | `needs-info`      | Waiting for information from the reporter            |
| `ready-for-agent` | `ready-for-agent` | Fully specified; ready for autonomous implementation |
| `ready-for-human` | `ready-for-human` | Human implementation required                        |
| `wontfix`         | `wontfix`         | Will not be actioned                                 |

Skills use the tracker label corresponding to each role. The tracker-label column is the source of truth for label overrides.
